01 土台

MainActivity.kt は MaterialTheme(colorScheme = if (dark) darkColorScheme() else lightColorScheme()) のみ。カスタム ColorScheme / Typography / Shapes は無い。テーマは ThemeMode(LIGHT / DARK / SYSTEM、設定画面で切替、即時反映)。

  • 配色: M3 標準の紫パレット。ライト/ダーク両対応。カスタム色は「作成」系・フェーズ・Pro バッジのみ(テーマ非追従)
  • フォント: 端末デフォルト(日本語は各社 Sans)。Figma では Roboto で作業してよい
  • 広告: BannerAdView — 帯(AnchoredAdaptive)は bottomBar、300×250(MediumRectangle)は商談詳細の本文中
  • edge-to-edge: 画面下端は Modifier.navigationBarsPadding()

02 M3 baseline カラー

lightColorScheme() / darkColorScheme() の値(上書きなし)。 下は代表値・参考。正確な hex は Figma の Material 3 Design Kit または Material Theme Builder で確認(Compose のバージョンで微差あり)。かっこ内は使用頻度。

container 系トークン(primaryContainer / secondaryContainer / tertiaryContainer …)は ライトとダークで役割が入れ替わる。デザイン時は必ず両方のフレームで確認する。

09 変えない前提

  • M3 テーマ機構(light/darkColorScheme())とライト/ダーク両対応
  • 独自色のテーマ非追従方針 — CreateActionBlue / PhaseTagColors / PhaseTrackerColors / ProGold
  • 広告枠の位置(収益に直結)。動かす場合は要相談
  • 画面下端の navigationBarsPadding()
  • 要約の項目順(サマリー→決定事項→懸念点・注意点→ToDo→次回打ち合わせ)は画面表示とエクスポートで共通
  • DB・ViewModel には触れず「表示だけ」の変更なら影響は UI 層に閉じる
