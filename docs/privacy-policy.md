## 2. 収集する情報と利用目的

### 2.1 音声(マイク)

本アプリは商談の録音のためにマイクへのアクセス(`RECORD_AUDIO` 権限)を使用します。録音開始時に「対面」または「リモート会議」のいずれかのモードを利用者が選択します。

#### 対面モード(既定)

- 音声は **端末内のオンデバイス音声認識機能** によってその場で文字起こしされます。
- **録音した音声データを端末外へ送信することはありません。** 文字起こしに用いた音声はファイルとして保存しません。

#### リモート会議モード(利用者が明示的に選択した場合のみ)

Web会議などスピーカー越しの相手の声を文字起こしするためのモードです。オンデバイス音声認識では遠くの音声を正しく認識できないため、次の方法で処理します。

- 録音した音声は端末内に一時ファイルとして保存され、**文字起こしのためだけに、本アプリ提供者が運用する中継サーバー(Cloudflare Workers)経由で Cloudflare の音声認識機能(Workers AI / Whisper)へ HTTPS 通信で送信** されます。
- 送信された音声は文字起こし結果の生成にのみ使用されます。**本アプリ提供者・中継サーバーは音声を保存しません。** Cloudflare 社によるデータの取扱いは同社の利用規約・プライバシーポリシー(https://www.cloudflare.com/privacypolicy/)に従います(Cloudflare は Workers AI の入力・出力を保存せず、モデルの学習に使用しないと表明しています)。
- 文字起こしが完了(または失敗)すると、端末内の一時音声ファイルは削除されます。
- このモードを初めて選択する際に、音声をサーバーへ送信することへの同意を確認します。同意しない場合はリモート会議モードを利用できません。

### 2.2 文字起こしテキスト・商談メモ

- 文字起こしされたテキスト、および要約結果(サマリー・決定事項・ToDo・次回打ち合わせ・懸念点)、クライアント名、商談タイトルは、**利用者の端末内のデータベースにのみ保存** されます。
- 要約生成のため、**文字起こしテキストを Anthropic PBC の Claude API(`https://api.anthropic.com`)へ HTTPS 通信で送信** します。送信されたテキストは要約結果の生成にのみ使用されます。Anthropic 社によるデータの取扱いは同社のプライバシーポリシー(https://www.anthropic.com/legal/privacy)に従います。
- 本アプリの提供者は、利用者の商談内容を独自のサーバーに収集・保存することはありません。

### 2.3 端末識別子(無料利用枠の管理)

- 無料利用枠(月あたりの無料要約回数)の管理のため、Android の端末識別子(`ANDROID_ID`)を **SHA-256 でハッシュ化した値** を端末内データベースに保存します。
- 元の識別子は保存せず、ハッシュ値を外部へ送信することもありません。

### 2.4 広告(AdMob)

- 本アプリは Google の AdMob を利用して広告を表示します。
- AdMob は広告配信のために、広告識別子(Advertising ID)、デバイス情報、おおよその位置情報、アプリの利用状況などを収集する場合があります。
- Google によるデータの取扱いは「広告 - ポリシーと規約 - Google」(https://policies.google.com/technologies/ads)および Google のプライバシーポリシー(https://policies.google.com/privacy)に従います。

### 2.5 エクスポート機能・データのバックアップ

- PDF / Word / メール文面のエクスポートは、利用者が共有先・保存先を明示的に選択した場合にのみ、当該アプリ・サービスへデータが渡されます。
- 設定画面の「データのバックアップ」から、利用者は自身の操作でアプリ内の全データを1つのファイル（JSON。任意でパスワード暗号化）に書き出し、任意の保存先（端末内・クラウドドライブ等、利用者が選択）へ保存できます。書き出し先は利用者が管理するものであり、本アプリの提供者へは送信されません。復元も利用者が選んだファイルからの手動操作です。

## 3. データの保存場所と第三者提供

| データ | 保存場所 | 第三者提供 |
|---|---|---|
| 音声データ(対面モード) | 保存しない | なし(端末外に出ない) |
| 音声データ(リモート会議モード) | 端末内に一時保存し、文字起こし後に削除 | 文字起こしのため中継サーバー(Cloudflare Workers)経由で Cloudflare(Workers AI / Whisper)へ送信。提供者・Cloudflare とも保存しない |
| 文字起こし・商談メモ | 端末内のみ | 要約時に文字起こしテキストを Anthropic(Claude API)へ送信。利用者が「データのバックアップ」を実行した場合のみ、利用者が選んだ保存先へ利用者自身の操作で書き出される |
| 端末識別子ハッシュ | 端末内のみ | なし |
| 広告関連データ | — | Google(AdMob)が収集 |

本アプリの提供者は、上記以外に利用者情報を第三者へ販売・提供しません。

## 4. 端末のバックアップ

本アプリは、Android のシステムによるクラウドバックアップおよび端末間データ転送の対象外に設定しています。本アプリで作成したデータが、利用者本人の端末外に自動的に保存・転送されることはありません。

## 5. 使用する権限

| 権限 | 用途 |
|---|---|
| マイク(`RECORD_AUDIO`) | 商談の録音・文字起こし |
| インターネット(`INTERNET`) | 要約API(Claude)との通信、リモート会議モードでの文字起こし(Cloudflare)との通信、広告の取得 |
| 通知(`POST_NOTIFICATIONS`) | 打ち合わせ・ToDo 期限のリマインド通知(利用者が任意でON) |

## 6. 児童のプライバシー

本アプリは13歳未満の児童を対象としていません。

## 7. データの削除

- アプリ内で作成したクライアント・商談・メモは、アプリ内の操作で個別に削除できます。
- アプリをアンインストールすると、端末内に保存されたすべてのデータが削除されます。
