プライバシーポリシー — 商談メモ

最終更新日: 2026-08-30

本プライバシーポリシーは、Androidアプリ「商談メモ」(以下「本アプリ」)における利用者情報の取扱いについて定めるものです。

1. 事業者情報

  • 提供者: manaapps
  • 連絡先: contact.manaapps@gmail.com

2. 収集する情報と利用目的

2.1 音声(マイク)

本アプリは商談の録音のためにマイクへのアクセス(RECORD_AUDIO 権限)を使用します。音声は端末内のオンデバイス音声認識機能によってその場で文字起こしされます。録音した音声データそのものをファイルとして保存したり、外部サーバーへ送信することはありません。

2.2 文字起こしテキスト・商談メモ

文字起こしテキスト、要約結果、クライアント名、商談タイトルは利用者の端末内のデータベースにのみ保存されます。要約生成のため、文字起こしテキストを Anthropic PBC の Claude API へ HTTPS 通信で送信します。送信されたテキストは要約結果の生成にのみ使用され、Anthropic 社の取扱いは同社のプライバシーポリシーに従います。本アプリの提供者は商談内容を独自のサーバーに収集・保存しません。

2.3 端末識別子(無料利用枠の管理)

無料利用枠の管理のため、Android の端末識別子(ANDROID_ID)を SHA-256 でハッシュ化した値を端末内データベースに保存します。元の識別子は保存せず、ハッシュ値を外部へ送信することもありません。

2.4 広告(AdMob)

本アプリは Google の AdMob を利用して広告を表示します。AdMob は広告識別子、デバイス情報、おおよその位置情報、アプリの利用状況などを収集する場合があります。Google による取扱いはGoogle 広告ポリシーおよびGoogle プライバシーポリシーに従います。

2.5 エクスポート機能

PDF / Word / メール文面のエクスポートは、利用者が共有先・保存先を明示的に選択した場合にのみ当該アプリ・サービスへデータが渡されます。

3. データの保存場所と第三者提供

データ保存場所第三者提供
音声データ保存しないなし
文字起こし・商談メモ端末内のみ要約時に文字起こしテキストを Anthropic へ送信
端末識別子ハッシュ端末内のみなし
広告関連データ—Google(AdMob)が収集

本アプリの提供者は、上記以外に利用者情報を第三者へ販売・提供しません。

4. 端末のバックアップ

本アプリは、Android のシステムによるクラウドバックアップおよび端末間データ転送の対象外に設定しています。本アプリで作成したデータが、利用者本人の端末外に自動的に保存・転送されることはありません。

5. 使用する権限

権限用途
マイク(RECORD_AUDIO)商談の録音・文字起こし
インターネット(INTERNET)要約API(Claude)との通信、広告の取得

6. 児童のプライバシー

本アプリは13歳未満の児童を対象としていません。

7. データの削除

アプリ内で作成したデータはアプリ内の操作で個別に削除できます。アプリをアンインストールすると、端末内に保存されたすべてのデータが削除されます。

8. 本ポリシーの変更

本ポリシーは必要に応じて改定されることがあります。

9. お問い合わせ

本ポリシーに関するお問い合わせは contact.manaapps@gmail.com までご連絡ください。
