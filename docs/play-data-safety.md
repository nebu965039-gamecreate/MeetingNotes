# Google Play データセーフティ フォーム記入ガイド — 商談メモ

Play Console >「ポリシーとプログラム」>「アプリのコンテンツ」>「データセーフティ」で入力する内容。
**このドキュメントはコードの実装(2026-09-08時点)に基づく。実装を変更したら見直すこと。**

---

## A. データ収集・共有の全体像

| 質問 | 回答 |
|---|---|
| アプリはユーザーデータを収集または共有しますか? | **はい** |
| すべてのユーザーデータは転送時に暗号化されますか? | **はい**(Claude API・Cloudflare 文字起こし・AdMob いずれも HTTPS) |
| ユーザーはデータの削除をリクエストできますか? | **はい**(アプリ内で個別削除 + アンインストールで全削除) |

> 「収集」= 端末外へ送信。「共有」= 第三者へ送信。
> 端末内にのみ保存され外部送信されないデータ(商談メモ本体、端末IDハッシュ)は「収集」に該当しない。

---

## B. データタイプ別の申告

### 1. 音声データ(録音)
- **収集する: はい / 共有する: はい**
- 対面モード(既定): オンデバイス音声認識でその場で文字起こしし、音声は端末外に出ない → それ単体なら「収集」非該当。
- **リモート会議モード(利用者が明示的に選択した場合のみ)**: 文字起こしのため、録音音声を提供者運用の中継サーバー(Cloudflare Workers)経由で Cloudflare の音声認識(Workers AI / Whisper)へ送信する。この経路があるため、フォーム全体としては音声データを **収集する=はい・共有する=はい** で申告する。
  - 目的: **アプリの機能**(遠隔・スピーカー越しの音声の文字起こし)
  - 目的(共有先): **アプリの機能**
  - 収集は必須ですか?: **任意**(利用者がリモート会議モードを選び、初回の同意ダイアログで承諾したときのみ送信。対面モードでは一切送信しない)
  - 処理は一時的ですか?: **はい**(中継サーバーは音声を保存しない。Cloudflare も Workers AI の入力・出力を保存せず学習にも使わないと表明。端末内の一時音声ファイルも文字起こし完了/失敗時に削除)
  - フォームの注記欄には「対面モードでは音声は端末外に送信されない。リモート会議モードでのみ、文字起こし目的で一時的に送信し、いずれの側でも保存しない」と記載。
- ※ 文字起こし後のテキストは下記 2 の経路(端末内保存 + 要約時に Anthropic へ送信)に合流する。

### 2. アプリのアクティビティ →「その他のユーザー生成コンテンツ」(文字起こしテキスト)
- **収集する: はい**
- **共有する: はい**(Anthropic PBC / Claude API へ要約処理のため送信)
- 処理は一時的ですか?: **いいえ**(Anthropic 側の保持方針に依存するため「いいえ」で申告するのが安全)
- 収集は必須ですか?: **必須**(要約機能の中核。ユーザーは要約を実行するか選べるが、実行時は送信必須)
- 目的: **アプリの機能**
- 目的(共有先):**アプリの機能**

### 3. デバイスまたはその他の ID
- **収集する: いいえ / 共有する: いいえ**(自アプリとして)
- 理由: ANDROID_ID の SHA-256 ハッシュを端末内DBにのみ保存。外部送信なし。
- ※ ただし下記「広告」で Google が広告IDを収集する点は別途申告。

### 4. 広告ID / おおよその位置情報 / アプリのインタラクション(AdMob 経由)
- **収集する: はい** / **共有する: はい**
- 収集主体: Google(AdMob SDK)
- 目的: **広告またはマーケティング**、**分析**
- 収集は必須ですか?: **必須**(無料版で広告表示のため)
- 該当データタイプ(AdMob が一般的に収集):
  - デバイスまたはその他の ID → **広告ID**
  - 位置情報 → **おおよその位置情報**
  - アプリのアクティビティ → **アプリのインタラクション**
- ※ 最新は AdMob の「Google Play データセーフティ」ヘルプで確認:
  https://support.google.com/admob/answer/11150250

### 5. 個人情報(氏名・メール等)
- **収集する: いいえ**
- アカウント登録なし。クライアント名はユーザーが任意入力する第三者の情報だが、端末内のみ・アプリ提供者は取得しない。

### 6. 財務情報 / 健康 / メッセージ / 連絡先 / カレンダー / 写真・動画 / ファイル
- **いいえ**(いずれも収集・共有しない)
- ※ エクスポートした PDF/Word はユーザーが明示的に共有操作した場合のみ外部アプリへ渡るため「収集」には非該当。

---

## C. セキュリティ対策のセクション

- 転送時の暗号化: **あり**
- データ削除のリクエスト方法: **あり**(アプリ内削除 UI / アンインストール)
- Play ファミリー ポリシー: 対象外(13歳未満向けではない)
- 独立したセキュリティレビュー: **受けていない**(該当すれば「いいえ」)

## D. 未確定・要判断ポイント

1. ~~`android:allowBackup`~~ → **`false` に決定済み**(+ 端末間転送も除外)。OSバックアップ経由のデータ移転は発生しない。
2. **Anthropic のデータ保持**: 「処理は一時的か」の回答は Anthropic の API データ保持ポリシー(現行: 悪用モニタリング目的で最大30日程度保持し得る)を確認して確定する。保守的に「一時的ではない」で申告済み。
3. AdMob の収集項目は SDK バージョン(`play-services-ads 25.4.0`)時点の AdMob 公式ヘルプで最終確認する。
4. **Cloudflare Workers AI の音声データ保持**: リモート会議モードの文字起こしで音声を Cloudflare Workers AI(`@cf/openai/whisper-large-v3-turbo`)へ送信する。Cloudflare は Workers AI の入力・出力を保存せず学習に使わないと表明しているが、最新の Cloudflare 利用規約・AI 補足規約・DPA(https://www.cloudflare.com/privacypolicy/ / Workers AI ドキュメント)を確認し、「処理は一時的=はい」で問題ないか最終確認する。中継 Worker(`server/src/index.ts` の `handleTranscribe`)は音声を KV/R2 等に一切書き込まない実装であることを確認済み。
